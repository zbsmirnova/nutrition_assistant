## Date authority follow-up — 2026-09-23

The smoke result also confirmed the intended boundary for date handling. The model may extract an explicit date phrase, but the backend resolves the effective date from source evidence, the original message date and the user's time zone. An undated source therefore uses its local source date even if the model returns an unsupported date hint. D013 records the decision; the focused resolver regression covers this case. Unsupported or conflicting date phrases remain unresolved.

Because this changes interpretation semantics for an existing source and hint combination, the resolver version advances from `single-food-resolver-v3` to `single-food-resolver-v4`. The conversation worker fences unfinished old interpretation contexts; prepared or applied commands resume from their stored command without reparsing.
